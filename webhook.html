Webhook ventes

Tu reçois l’argent de tes produits. Ce webhook enregistre les commissions dues à tes promoteurs — le Super Admin ne les paie pas à ta place.

Format générique (n’importe quel outil de paiement)

POST JSON vers ton URL. Champs utiles :

{}
  • email — acheteur
  • amount — montant de la vente
  • ref — code unique du promoteur (empreinte)
  • product_id — id produit Répertoire (optionnel mais recommandé)

Systeme.io

  • Automatisation → Nouvelle vente → Webhook
  • Colle ton URL ci-dessus
  • Le champ ref doit voyager avec le lien d’affiliation du promoteur

Sans signal de vente (webhook), les commissions ne s’écrivent pas — quel que soit l’outil.
